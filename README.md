# 离线网页保存器 (Offline Web Saver)

Windows 桌面工具：左侧输入网址、右侧即时浏览，一键把当前网页保存成**单文件 HTML**。图片、CSS、字体全部内联，断网可打开，页面元素仍可点击、输入、展开。

保存前会自动清除网页自身的弹窗、登录框、Cookie 提示与灰色遮罩，落盘的是干净正文。

## 功能

- **左右分栏**：左栏填网址与选项，右栏用 QtWebEngine 真实渲染网页（所见即所存）
- **保存前清理弹窗**：等待页面稳定后清理一次，滚动触发懒加载后再清理一次；覆盖语义化对话框、主流组件库遮罩、大面积 fixed 浮层，并解除 body 滚动锁定，同源 iframe 内部同样清理
- **原生对话框自动应答**：alert / confirm / prompt 不阻塞保存流程
- **懒加载触发**：自动滚动到底再回顶部，长页面图片不漏
- **单文件输出**：全部资源内联，产物为一个可离线打开、可交互的 `.html`
- **预览已保存页面**：右栏可直接打开本地 `.html` 查看效果

## 界面

左侧自上而下：网址输入框 + 打开、保存目录、预览已保存的网页文件、保存前等待秒数、保存选项、保存当前网页、运行日志。
右侧：后退 / 前进 / 刷新 + 网页画面。

## 保存选项

| 选项 | 默认 | 说明 |
|---|---|---|
| 保存前自动关闭网页弹窗 | 开 | 先清弹窗遮罩再抓取 |
| 先滚动页面触发懒加载图片 | 开 | 滚动到底再回顶部，触发懒加载 |
| 移除隐藏元素 | 开 | 去掉 display:none 内容，减小体积 |
| 移除未使用的样式与字体 | 开 | 只保留实际用到的 CSS 与字体 |
| 保留框架/内嵌页面 | 开 | 保留 iframe 内容 |
| 保存后自动打开文件 | 关 | 完成后用默认浏览器打开成品 |

## 快捷键

- `Ctrl+S` 保存当前网页
- `F5` 刷新右侧页面
- 地址栏回车直接打开

## 运行源码

```bash
pip install -r requirements.txt
python offline_web_saver.py
```

`sflib/single-file.js` 为必需依赖，需与脚本同级放在 `sflib/` 目录下。

## 打包 exe

```bash
pyinstaller --noconfirm --clean build.spec
```

产物为单文件 exe，约 142 MB。单文件模式每次启动需自解压，首次启动 15~40 秒属正常；若需秒开，可改用目录模式（`COLLECT`）打包。

## 已知限制

- 依赖后端接口的功能（点赞、加载更多）离线后必然失效，纯前端交互正常
- 页面过大或脚本被站点拦截时可能生成超时，可调大"保存前等待"
- 顽固浮层若未被识别，可在右栏手动点掉后保存
